## Sobre mim

Sou desenvolvedor **Full Stack** e trabalho com o ciclo completo de um produto: levantamento de requisitos com a área de negócio, modelagem de dados, APIs, interface, testes automatizados e **deploy**.

- 🧩 Desenvolvo **APIs REST** e **integrações entre sistemas** via API e bancos de dados externos
- 🗄️ Trabalho no dia a dia com **PostgreSQL** e **SQL Server**
- ☁️ Opero ambientes em **AWS** e **Azure**
- 🚀 Cuido do **deploy**, de CI/CD, backups e segurança dos servidores
- 🔐 Levo segurança e LGPD a sério: autenticação, controle de acesso granular e criptografia de dados

## Projeto em destaque

### 🎫 [Sistema de Chamados — PixCard](./sistema-chamados-pixcard.md)

Plataforma de abertura e gestão de chamados que desenvolvi de ponta a ponta para a **PixCard**, usada pelas equipes internas e pelas empresas parceiras.

- **Next.js + Node.js + PostgreSQL**, com arquitetura hexagonal e monorepo TypeScript
- SLA calculado em horário comercial, chat em tempo real e notificações push
- Controle de acesso por perfil com 29 permissões e integração com o sistema core da empresa
- **638 testes automatizados**, CI no GitHub Actions e deploy automatizado
